# Windows USB driver signature verification

USB Doctor now opens a Windows Authenticode verifier backed by WinVerifyTrust. It verifies the selected .cat catalog signature or an embedded signature in a .sys, .dll or .exe file and reports the Windows trust status, signer subject, thumbprint and certificate validity dates.

A CAT-only result confirms the publisher signature on that catalog file, not membership of a separate driver. When both the OEM CAT and a SYS/INF/DLL/EXE member are selected, the verifier locates a trusted Microsoft SignTool from an installed Windows SDK and runs `signtool verify /v /pa /c CatalogFileName.cat DriverFileName` using argument-safe process invocation. Microsoft documents `/c` as selecting the catalog that contains the file and `/pa` as the PnP installation signing policy. If SignTool is unavailable, the membership result remains unverified; SoftBox never reports a pass from a CAT-only signature. The verifier does not install a driver, modify Driver Store, or prove model compatibility. The official Samsung installer retains its separate Authenticode check in the packaging workflow.
